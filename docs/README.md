# docs

- `decisions/` — 구현 중 내린 기술적 결정과 그 이유(ADR 형식의 짧은 기록).

전체 제품 요구사항·화면 설계·AI 규칙·시스템 구조는 프로젝트 착수 시 공유된 "DearDarling 요구사항 및 설계 v0.1" 문서(대화 기록)를 기준으로 한다. 별도 파일로 옮겨 담는 작업은 필요해지면 진행한다.

단, 일부 규칙은 구현 중 갱신됐다. 특히 **`decisions/0004`는 v0.1의 "패턴 양측 '맞아요' 확인 후 코칭 활용" 방식을 대체**한다 — 관찰을 미확인 가설로 먼저 보여주고, 의견 덧붙이기·코칭 활용 중단을 선택 사항으로 둔다. 상충하는 경우 `decisions/`가 우선한다.
