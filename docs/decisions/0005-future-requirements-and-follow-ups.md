# 0005 — 향후 요구사항과 후속 작업

날짜: 2026-09-09

화면 검토 단계에서 범위 밖으로 두되 잊지 않기 위해 기록한다. 각 항목은 실제 착수 시 별도 결정
문서(ADR)로 구체화·확정한다. 이 문서는 "무엇을 아직 안 했는지"의 목록이다.

## 후속 화면·연결 (예정, 범위 밖)

- **가입 / 로그인 / 연인 연결 화면.** 여러 화면 사이를 실제로 이동하고 브라우저 히스토리·딥링크가
  필요해지는 시점이다. 이때 **react-router를 도입**하고(0001·0003 참조) 현재 상태 기반
  `NavigationContext`를 재검토한다.
- 실제 인증·DB·AI·AWS 연결 (`apps/api`, `apps/worker`, `packages/contracts`, `packages/domain`, `infra`).

## 채팅 사진·영상 (구조만 준비, 기능 예정)

- 화면 검토 단계에 포함: `MessageAttachment`(`kind: 'image' | 'video'`, `fileName`, `previewLabel`)
  타입 구조, 말풍선 자리표시자 렌더, 시드 예시(이미지 1건·영상 1건), 추억 저장 시 사진·영상 종류 표시.
- **예정**: 실제 업로드·저장·재생. 첨부 버튼은 현재 비활성이며 "추후 지원" 안내만 보여준다.
  실제 구현 시 `MessageAttachment`에 `storageKey`, `mimeType`, `width/height`, `durationMs`,
  `sizeBytes` 등을 추가한다.

## 별도 검토 항목 (확정된 기능 아님)

- **사진·영상의 AI 분석.** 대화 맥락 이해에 도움이 될 수 있으나 민감도가 높아 별도 검토가 필요하다.
  현재 계획에 포함되지 않는다.
- **관찰에서 실제 코칭 문구를 생성하는 로직.** 0004의 규칙을 지켜야 한다 —
  `isExcludedFromCoaching`인 관찰은 양측 코칭에서 제외, "두 사람이 남긴 의견"이 있는 관찰도
  단정 없이 가설로만 활용.
- **분석 철회 후 관찰·의견·중단 선택의 보존·삭제·복원 정책.** 0004에서 미정으로 남겨 둔 항목.
  화면 검토 단계에서는 화면 차단만 확인했고, 데이터 수명·재동의 시 동작은 정하지 않았다.
