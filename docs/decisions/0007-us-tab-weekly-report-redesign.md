# 0007 — '우리' 탭을 핵심 발견 하나 중심의 주간 리포트로 개편

날짜: 2026-09-09

## 배경

0006에서 올린 '우리' 탭은 비슷한 관찰 카드 4개(`PatternObservationCard`)를 나열하고, 카드마다
`미확인 가설` 칩과 잠정 안내가 반복돼 화면이 길고 딱딱하게 읽혔다. 통계는 맨 아래 접힌 섹션에
묻혀 있었다. 이번 개편은 **이번 주의 핵심 발견 하나**를 중심으로 리포트를 다시 구성한다.
여전히 실제 AI·DB를 연결하지 않는 가상 데이터 화면 검토 단계다.

0006 §3(소통 패턴 관찰 카드)은 이 문서로 대체된다. 0004(패턴 관찰·코칭 활용 모델)의 핵심 규칙은
그대로 유지한다.

## 결정

### 1. 통계를 상단으로 (`WeeklyStatsStrip`)

- 접힘형 `이번 주 통계 · 보조 참고` 섹션을 상시 노출형 스트립으로 교체. 위치는 상단 안내 바로 아래.
- 핵심 통계 3개 타일 + 요일별 작은 막대 그래프(인라인 CSS, 장식 아님) + 하이라이트 1~2줄:
  - 주고받은 메시지(`stats.totalMessages`)
  - 대화한 날(`stats.daysWithConversation` / `stats.activeDaysTotal`, 같으면 "매일")
  - 대화가 많았던 요일(`stats.byWeekday`의 최댓값에서 파생 — 필드로 저장하지 않는다)
- **관계 점수·두 사람 순위는 넣지 않는다**(0005에서 관계 점수는 '보류').
- 통계와 대표 발견 분석글의 내용이 서로 맞도록 시드를 구성한다. `highlights`는 **통계로 뒷받침되는
  범위만** — 요일 통계만 있는데 '금요일 저녁'처럼 시간대까지 단정하지 않는다.

### 2. 이번 주 핵심 발견 하나 (`HeadlineFinding`)

- `WeeklyReport.headlineObservationId`가 가리키는 관찰 하나를 `이번 주 눈에 띈 우리 모습` 아래에
  보여준다. 구성: 자연스러운 제목 + 흐름 도식 + 관찰한 모습 + AI 해석 + 근거 인용 + 작은 실천 하나.
  제목·도식·본문이 서로 내용을 반복하지 않게 **짧게** 유지한다.
- 나머지 관찰은 `다른 발견 보기`(기본 접힘)에 둔다. 각 카드의 의견·코칭 제외 설정은 그대로 유지.
- **대표 발견은 가상 데이터로 지정**한다(`SEED_WEEKLY_REPORT.headlineObservationId = 'pat-1'`).
  실제 분석에서 눈에 띄는 관찰이 부족하면 **억지로 관찰을 만들지 않는다.**
- **관찰이 0건인 것만으로는 '대화 부족'이 아니다.** '대화 부족'(리포트를 만들 만큼 대화가 없는 상태)은
  `scenario === 'empty'`로만 판단한다. 대화·통계가 충분한데 이번 주 관찰·대표 발견이 모두 없으면,
  대표 발견 자리에 "이번 주는 특별히 눈에 띈 흐름은 없었어요"만 보여주고 **통계 스트립은 그대로
  유지한다.** (`ReportBody`의 게이팅에서 `observationCount === 0` 조건을 뺐다.)
- 검토 도구(DevPanel)에 "주간 리포트 · 이번 주 발견 있음/없음" 토글을 둬 확인한다. '없음'은 이번 주
  관찰 목록을 빈 배열로 흉내 낸다 — 대표 발견도 '다른 발견 보기'도 사라지고, 통계와 안내만 남는다.
  '빈 대화'(대화 부족) 상태와는 다른 화면이다.
- **`PatternContext`에서 리포트 표시용 목록과 코칭 제외 목록을 분리한다.** `observations`(표시용)는
  `weeklyFindingsPresent`에 따라 빈 배열이 될 수 있지만, `excludedPatternIds`는 항상
  `storedObservations`의 제외 설정으로만 계산한다. 검토용 '발견 없음' 토글이 이미 제외한 관찰의
  양측 대화 코칭 숨김을 되돌리지 않는다.

### 3. '미확인 가설' 문구 제거

- 반복되던 카드별 상태 칩(`미확인 가설` / `코칭에서 제외됨`)을 없앤다. 상단에서 한 번만 안내한다:
  > "대화에서 이런 모습이 보였어요. 두 사람이 느낀 것과는 다를 수 있어요."
- 본문은 부드럽게 — `관찰한 모습`(사실), `이렇게 이해해 볼 수도 있어요`(해석), `이런 흐름이 있었어요`.
- `observationStatusLabel`을 제거하고 `coachingExclusionNote(observation)`로 대체한다 — 제외 상태면
  `'지금은 코칭에 사용하지 않고 있어요'`, 아니면 `null`.
- 의견이 없거나 두 사람이 의견을 남겼다고 해서 관찰을 확정된 사실로 바꾸지 않는다(라벨·문구 불변).

### 4. 짧은 분석글 + 근거 + 실천 하나

- 대표 발견은 `PatternObservation`의 선택 필드로 표현한다(예전에 저장된 관찰엔 없을 수 있음 → 방어):
  - `title` — 없으면 "이번 주 눈에 띈 흐름"으로 대체
  - `interpretation` — AI 해석 문단(최대 2, 합쳐 짧게). 없으면 그 블록을 렌더하지 않는다.
    **관찰 사실을 되풀이하지 않고 "왜/어떻게 볼까"만.** 상대의 속마음·성격은 단정하지 않는다.
  - `evidenceQuotes` — 근거 인용 여러 장면. 없으면 `[evidenceText]`.
  - `flow` — 흐름 도식의 단계 라벨(보통 3개). 라벨만 — 문장으로 다시 설명하지 않는다.
- **관찰 사실과 AI 해석을 화면에서 분리한다.** '전문가가 검토했다' 같은 표현은 쓰지 않는다 —
  근거 인용과 글의 완성도로 신뢰감을 준다.
- 시각 자료는 내용을 설명하는 작은 그래프·도식만. **사진·영상 AI 분석은 이번 범위 밖.**
- 근거는 발견을 뒷받침하는 범위여야 한다. pat-1의 "며칠 뒤 다시" 부분은 그 흐름을 보여주는
  두 번째 인용을 함께 둔다(근거 없이 발견만 넓히지 않는다).

### 5. 기존 핵심 규칙 유지

- 의견·코칭 제외 조작은 펼침 영역(`ObservationControls`)에 둔다. **조작 전에 공개·적용 범위를
  먼저 안내한다.** 이 안내는 의견 공개와 코칭 제외 적용을 **한 문장씩 구분**한다 —
  "남긴 의견은 상대에게도 보여요. 코칭에서 제외하면 두 사람의 관련 코칭에 모두 적용돼요." 여기에
  더해, 의견 입력창을 열면 그 위에 "상대에게도 보여요"를 다시 보여주고, 코칭 제외 토글 위에는
  범위 안내를 항상 표시한다.
- **제외된 관찰은 관련 실천 제안과 양쪽 대화 코칭에서 계속 제외**한다. `HeadlineFinding`은 제외 시
  `작은 실천 하나`를 숨기고 부드러운 안내로 대체한다. `excludedPatternIds` →
  `coachingService`(0004 §5) 경로는 그대로다. **분석글(`interpretation`)에 같은 조언을 넣어 제외
  설정을 우회하지 않는다** — 시드 데이터에서 지키고, 실제 코칭 문구 생성 로직(0005)도 이를 따른다.
- 제외 상태는 `지금은 코칭에 사용하지 않고 있어요`처럼 부드럽게 표시한다.
- 분석 동의·철회 게이팅, 본인 의견만 수정·삭제, 제외 해제는 본인 것만, 계정 전환 격리(카드 접힘·
  초안 폐기), AI 개인 상담 진입점 — 모두 그대로.

## 검증

- `apps/web/src/mocks/domain/__tests__/patterns.test.ts` — `coachingExclusionNote`(제외 시 문구,
  아니면 null; 의견 유무 무관), `isExcludedFromCoaching`·`canRevokeOptOut`·`opinionSummary` 유지.
- `apps/web/src/features/week/__tests__/WeekPage.test.tsx` —
  - 상단 통계 스트립(메시지 수·대화한 날·많았던 요일·요일 막대·하이라이트)이 펼치지 않아도 보임;
    관계 점수·순위 없음; 하이라이트에 시간대('저녁') 단정 없음.
  - 상단 잠정 안내 1회, `미확인 가설` 텍스트 0건.
  - 대표 발견: 제목·도식·관찰·해석(≤2문단)·근거 인용 2개·작은 실천 하나.
  - 의견·코칭 제외는 펼쳐야 보이고, 펼치면 의견 공개/코칭 제외 안내가 **한 문장씩 구분**돼 먼저 나옴.
  - `다른 발견 보기` 접힘/펼침, 각 카드의 의견 수정·계정 전환 시 초안 폐기, 제외 카드 표시.
  - 대표 발견 제외 → 실천 제안 가림 + 양측 대화 화면 코칭 가림(0004 §5), 마지막 해제로 복구.
  - **관찰 0건이어도 '대화 부족'으로 판단하지 않음** — 통계 + '눈에 띈 흐름 없음' 안내 유지,
    '다른 발견 보기' 없음. `scenario === 'empty'`(빈 대화)만 통계 없는 상태 카드.
  - **검토용 '발견 없음'이 코칭 제외를 무효화하지 않음** — 관찰 제외 → 양측 코칭 숨김 →
    '이번 주 발견 없음' 전환 후에도 양측 코칭 계속 숨김 → '발견 있음' 복귀 시 제외 유지.
  - 분석 철회 / `ai-warming-up` / `ai-failure` 상태, `coachingVisible`만 끈 경우 리포트 유지.
- `Navigation.test.tsx`, `HomePage.test.tsx`, `AskAiPage.test.tsx` — 우리 탭 진입 확인 앵커를
  `이번 주 눈에 띈 우리 모습`으로 갱신.
- `pnpm test` · `pnpm typecheck` · `pnpm lint` · `pnpm build` · `pnpm format:check`.

## 이후 범위 (0005 계열)

- 관찰에서 실제 코칭·해석 문구를 생성하는 로직. 위 §5의 "제외 우회 금지"를 반드시 따른다.
- 대표 발견 선정 기준(실제 분석). 강한 관찰이 없으면 `headlineObservationId = null`.
- 분석 철회 후 관찰·의견·제외 선택의 보존·삭제·복원 정책은 여전히 미정.
